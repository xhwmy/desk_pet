# Bamboo Duo internal wallpaper

The active setup customizes only the internal Codex client wallpaper with
C (Moonlit Fireflies). The sidebar shares the same background. A soft pale-green
gradient keeps the native black window buttons readable.

The external B opening was removed at the user's request. Deployed opening
players, preview entrypoints, readiness files, and temporary restart-test tasks
were deleted. Desktop and Start Menu entries now open the real client directly
through the internal-wallpaper helper. No independent opening image is shown.

scripts/Start-CustomCodex.ps1 starts or reuses the installed Store client and
applies the selected internal theme. CodexSkinStudio remains the background
wallpaper recovery task. Theme selection and artwork are retained under
build/DragonCodexBoot/wallpaper and duo/art-options.

The original downloaded launcher's source remains for reference. Rebuilding or
packaging that source is unnecessary for the active internal-wallpaper setup.

Community sharing remains a local preview only. Nothing has been uploaded.
