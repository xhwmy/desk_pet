# Source attribution

This directory includes source from
https://github.com/yushua0808-cpu/dragon-codex-boot at commit
d3b7bb84b75134f8250491c86d72996a70d58165, with local modifications.
The upstream MIT license and notices are retained in LICENSE and
THIRD_PARTY_NOTICES.md.

The current local integration uses Bamboo Duo only as an internal Codex
wallpaper. The independent opening window has been removed from active startup
and recovery paths. The original launcher source is retained as historical
source, and is not a replacement for the native Codex startup screen.

Generated wallpaper options are in duo/art-options. Original user reference
attachments, desktop and chat screenshots, local configuration, logs, shortcut
backups, private Git metadata, and compiled launchers are not included.
