# 赤焰 Windows 独立桌宠

这是赤焰的独立 Windows 版本，沿用 Python／PyQt。当前 `assets/spritesheet.png` 复用项目已有的轻呼吸待机图集，`assets/actions/` 复用此前制作的六套完整关键帧动作。历史 `assets/spritesheet.webp` 保留为原始素材。此程序不会修改 Codex 客户端或其中的宠物。

## 使用

将 `Chiyan-DesktopPet.exe` 拷贝到任意位置，双击运行。适用 64 位 Windows 10/11；无需安装 Python、PyQt、Codex 或联网。首次启动单文件程序需要临时解包，可能稍慢。

- 单击挥手并轻微回弹；双击跳跃。单击会等系统双击判定时间结束后响应，避免抢先播放挥手。
- 左键拖动有弹簧跟随感。轻放停在鼠标指定位置，快速甩出则受重力下落、碰工作区边界反弹、落地摩擦停稳。
- 右键“动作”包含理头发、整理衣领、抱膝打盹、伸懒腰、敲小键盘、左右探头，以及挥手、跳跃、等待、认真思考。
- 每套动作按自身帧时长完整播放，结束后回到轻呼吸待机；切换有约 180 毫秒淡入，不会凭空补出运动中间帧。
- 空闲 12–22 秒后按权重选择下个动作，避免连续重复；自动漫游只沿当前高度走 60–180 像素。手动“朝鼠标走来”仍可向鼠标位置移动。
- 靠近宠物时会朝鼠标方向看；自动活动不会打断手动动作、拖拽或抛掷。
- “暂停自动活动”停止自动漫游并结束正在进行的位移，手动动作仍可用。“减少动效”关闭淡入、挤压、甩抛及自动行走／跳跃。
- 托盘图标可操作，双击托盘图标可找回宠物。
- 位置、大小、暂停和减少动效状态会记住。缩放保持脚底位置，重置／缩放会取消正在进行的抛掷。

![真实 Qt 播放器预览](motion-preview.gif)

当前素材是每套六张关键姿势，打盹和打字通过合理停顿／重复延长。它不是 DSH 项目的 24 fps 透明视频，不能承诺同等连续运动；新增连续动作需要另外制作足够的中间帧或视频素材。跨显示器拖动可用，甩抛限制在当前显示器工作区，不实现跨屏抛掷。

截图底部的按钮属于 Codex 应用界面，不是宠物素材；此程序提供自己的右键和托盘菜单。

## 开发构建

开发电脑安装 Python 后，在本目录运行：

```powershell
python -m pip install -r requirements-build.txt
.\build.bat
```

输出为 `dist/Chiyan-DesktopPet.exe`。构建工具只在开发电脑上需要。

测试：`python -m unittest discover -s windows-chiyan -v`（从仓库根目录运行）。Qt 测试使用 offscreen 平台和临时 INI，不修改用户偏好。

素材已随源码打包；需要从原始资料重新复制时，运行 `python windows-chiyan/prepare_assets.py`。该步骤仅原样复制现有素材并生成播放清单，不调用生图、不修改原始帧。`python windows-chiyan/render_preview.py` 使用真实 Qt 播放器导出预览，需要开发环境另装 Pillow。

可选动作包位于 `assets/actions/clips.json`：每个动作指定 `frames` 相对路径数组及等长的 `durations_ms` 数组。帧需为 192×208 透明 PNG，统一角色大小及脚底基线；不得覆盖内置动作。加载错误时保留基础动作并在右键菜单提供错误说明，不会把半套损坏动作加入播放池。

参考来源与素材说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
